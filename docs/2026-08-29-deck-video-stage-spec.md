```
└── src/

    ├── deck-params.ts             # 生成物（脚本产出，勿手改）
    └── deck-cues.ts               # 生成物（脚本产出，勿手改）
```

### 契约 1 · 口播稿（narration 站格式，ref 指页）

`output/video-motion/deck-test/script.json`：字段与 narration spec §2 完全一致（meta.title / lang / budgetSeconds / charsPerSecond；segments[].id / kind / text / ref），**ref 写 `"page N"`**（N=1..10）。分段稿必须先过 `python skills/narration/templates/verify_narration.py <script.json>` 全绿（budgetSeconds = Σ 页音频预估，写稿时先按 4.5 字/秒估，配音后以实际为准，只校验结构/段长/禁令）。

### 契约 2 · `extract_pages.py`（pptx → 页图）

```
python extract_pages.py <in.pptx> <outDir>
```

- win32com：`PowerPoint.Application` → `Presentations.Open(<绝对路径>, True, False, False)` → `SaveAs(<outDir>/deck.pdf, 32)` → `Close()` → `Quit()`
- fitz 渲染：`get_pixmap(dpi=200)` 逐页存 `p-<N>.png`（1 起始，N = PDF 页序）
- 完成打印：`pages=N dpi=200 out=<outDir>`（英文）；异常退出码 1

### 契约 3 · `make_deck_audio.ps1`（分段稿 → 逐页 SAPI 配音）

```
powershell -File make_deck_audio.ps1 <script.json> <outDir>
```

- `ConvertFrom-Json` 读分段稿；按 `ref` 的页号聚合每页文本（页内多段以句号连接）
- System.Speech，`SelectVoice("Microsoft Huihui Desktop")`，逐页 `SetOutputToWaveFile` 出 `page-<N>.wav`
- 每页之间天然换 wav 即间隔，无需 AppendBreak；打印各页路径
- **正式流程替换点**：人工在剪映逐页配音，导出同名 `page-N.wav` 放同目录即可，下游无感

### 契约 4 · `build-deck-params.mjs`（派生值生成器，设计即代码）

```
node scripts/build-deck-params.mjs <script.json> <deckDir>   # deckDir = public/deck
```

- ffprobe 逐个 `audio/page-N.wav` 时长 → `audioSeconds[N]`；页时长 `pageSeconds[N] = audioSeconds[N] + 0.4`（呼吸）
- 页全局起点：`start[N] = Σ pageSeconds[1..N-1]`（音频即从页起点播）
- 总时长：`totalSeconds = Σ pageSeconds + 0.5`（末页交叠尾）
- 生成 `src/deck-params.ts`：

```ts
// AUTO-GENERATED by scripts/build-deck-params.mjs — 换素材/稿/配音后重跑，勿手改
export const deckParams = {
  fps: 30, width: 1920, height: 1080, overlapSeconds: 0.5,
  pages: [{ index: 1, start: 0, audioSeconds: 12.3, pageSeconds: 12.7 }, /* … */],
  totalSeconds: 128.4,
} as const;
```

- 字幕摊时：页内各段在该页音频窗 `[start, start+audioSeconds]` 内按剥后字数比例线性摊 → 全局 `SubtitlesCue {start, end, text}`（**类型与首站 SubtitleCue 逐字段一致**），生成 `src/deck-cues.ts`：

```ts
// AUTO-GENERATED by scripts/build-deck-params.mjs — 勿手改
export const deckCues: { start: number; end: number; text: string }[] = [ /* … */ ];
```

### 契约 5 · `DeckVideo.tsx`（组合）

```tsx
// 每页一个 Sequence：渲染窗 = pageSeconds + overlapSeconds（交叠尾）；
// 前 0.5s spring 淡入（damping 200 + translateY 24px 上浮），后 0.5s 淡出 → 相邻页交叉溶解
// <Img src={staticFile(`deck/pages/p-${index}.png`)} /> 铺满（objectFit: contain，页图 2667×1500 缩到画布）；
// <Audio src={staticFile(`deck/audio/page-${index}.wav`)} /> 放在页 Sequence 内即随页起止
// 顶层挂 <SubtitleTrack cues={deckCues} />（复用首站 fx/SubtitleTrack，不改它）
```

- Root.tsx 注册 `DeckVideo`：`fps/width/height` 取 deckParams，`durationInFrames = Math.round(deckParams.totalSeconds * deckParams.fps)`
- 字数摊时与 spring 都是时间基（秒），不依赖具体 fps，逻辑与首站一致

1. 写 `output/video-motion/deck-test/script.json`：约 10 段（每页 1 段为主），内容讲 vibe-studio 自己是什么（对页图真实内容负责：封面页讲定位、各内容页讲该页要点、尾页讲收束）；`budgetSeconds` 先按 Σ(每段字数/4.5)+15% 估
2. `python skills/narration/templates/verify_narration.py` 全绿（红 → 改稿不改规则）
3. 按契约 3 实现 `make_deck_audio.ps1` → 跑出 `public/deck/audio/page-1..10.wav`
4. ffprobe 逐页记录时长，写入验收文件（后续对账基准）

**完成标志**：稿全绿 + 10 个 wav 齐全。**提交**：`git add skills/video-motion/templates/remotion-app/scripts/make_deck_audio.ps1` → `feat(deck-video): Stage 1 分段稿与逐页配音 / stage 1 script and per-page audio`

### Stage 2 · 接线与元数据验证

1. 按契约 4 实现 `build-deck-params.mjs` → 跑出 `src/deck-params.ts` + `src/deck-cues.ts`
2. 按契约 5 实现 `DeckVideo.tsx` + Root.tsx 注册
3. `npx remotion compositions remotion/index.ts` → `DeckVideo` 行的总帧数应 = round(totalSeconds×30)，与手算 Σ 一致

**完成标志**：compositions 输出与 deck-params 对账一致。**提交**：`git add skills/video-motion/templates/remotion-app/scripts/build-deck-params.mjs skills/video-motion/templates/remotion-app/src/DeckVideo.tsx skills/video-motion/templates/remotion-app/src/deck-params.ts skills/video-motion/templates/remotion-app/src/deck-cues.ts skills/video-motion/templates/remotion-app/src/Root.tsx` → `feat(deck-video): Stage 2 逐页组合接线 / stage 2 per-page composition wiring`

### Stage 3 · 渲染 + 三级自验收

渲染：`npx remotion render remotion/index.ts DeckVideo ../../../../output/video-motion/deck-test/deck.mp4 --crf=16`

**L1 程序级**：退出码 0；ffprobe 时长 ≈ totalSeconds（±1s）、1920×1080、30fps；`compositions` 对账。
**L2 抽帧 ≥10**（`npx remotion still`，PNG 到 `output/video-motion/deck-test/frames/`，`C:\pc\` 读图）：

| 帧 | 期望 |
|---|---|
| 每页首帧 +0.3s（10 帧） | 页序 = p-1…p-10 依次出现，无跳页无重复 |
| 任取 2 个页间交叠中点（下页 start − 0.25s） | 两页叠影渐变中，无黑帧 |
| 任取 2 条字幕的 start+0.3s | 字幕文本 = 分段稿对应段 |
| 任取 1 条字幕的 end+0.3s | 字幕已退 |

**L3 报告**：`output/deck-video-acceptance.md` 汇总 L1+L2 全表、渲染输出、结论 `ALL GREEN` 或红项清单。红 → 修对应环节重跑；连续 2 轮红 → 停下报告。

**完成标志**：全绿报告落盘。**提交**：`git add` 无新增跟踪文件则不提交（渲染与报告均在 gitignored 区），如实记录。
