# 视频质量规范

2026-10-23 调整。保留原有浅米白杂志 / 深蓝科技品牌语言；将单片经验改为按内容选择的设计准则。旧版背景与教训仍可从 Git 历史和工单台账查阅。

## 先按内容选择

| 类型 | 主体与信息 | 运动与节奏 | 审阅重点 |
|---|---|---|---|
| 产品/教程演示 | 真实界面、关键操作和结果 | 用特写、裁切或操作顺序解释 | 观众能否复述步骤，手机能否读清 |
| 数据/概念解释 | 已核实数据、关系、结构图 | 运动展示变化与因果，不做持续装饰 | 口径、比例、标注与来源 |
| 故事/情绪表达 | 有叙事作用的人物、场景与细节 | 允许静止与留白，节奏服务情绪 | 焦点、氛围与叙事连续性 |
| 模板/管线测试 | 明确标注的测试素材 | 验证边界与确定性 | 不能把 Demo 当正式品牌片 |

## 视觉与美术

- 主体应由内容决定；浅/深背景族、字阶和版式是默认品牌语言，可按镜头目标调整。
- 在目标画幅和手机尺寸检查可读性；大字、阴影和细线没有全片固定配额。元素过多、字体过小或与字幕重叠时删减或重排。
- 留白服务焦点和节奏，不用“空区不能超过 20%”逼迫每镜填满；每镜需要多少支撑信息由内容决定。
- 运动应帮助解释、引导注意或传递情绪。允许稳定的阅读镜头；单张静帧不能证明“有无视频感”。用连续片段检查节奏，不为通过检查添加呼吸光环。
- 真实截图/录像、SVG、插画分别服务演示、结构与美术需求。需要插画的镜头优先真实美术素材；CSS 负责布局和适合的简单几何，不以实现技术判断美术质量。
- 全片字体与色板有单源；道具放大检查细节，真实界面截图不能缩到不可读。字幕融入版面，避免与同一条画面大字重复。

## 技术检查与人工接受

1. L1：ffprobe 规格与声明一致，完整解码、帧数/时长对账、字幕窗口与响度检查。按项目设参数，失败需要修复。
2. L2：关键镜头的进场、稳定态、信息变化和切点实际抽帧，检查乱码、裁切、对比度与遮挡。需要时看道具特写。
3. L2.5：按内容类型做静音复述或听音检查；叙事片允许关键信息依赖旁白，不套每页固定信息数量。
4. L3：看短样片及全片节奏；首/中/尾听同步，检查背景音乐与人声关系，核对横竖版及封面安全区。
5. 人工终审单独记录。media-qc 的 technical-pass-needs-human-review 只代表机器范围，不能自动改为 accepted。

正文数据与来源不清、画面主体错误、文字截断/乱码、缺帧、误用旧视频等属于交付阻断项。短黑场、静止片段、留白与风格偏好需要结合具体镜头判断；不以固定数量的动效证明成片质量。
