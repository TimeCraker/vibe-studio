# 动效语法（Motion Grammar）— 从标杆片拆解的通用规则

> 来源：Claude 逐帧拆解 B 站标杆片 BV1fShG6LETU（《为什么 AI 越来越强…Agent 实战》，6'49"，1080p30，17.5 万播放），2026-08-30。
> 采样方法：14 个场景转场点切 15 段、每段抽稳定帧全片覆盖 + 4 段密集抽帧看进场动画（v2 修订：初版曾以开场行星段概括全片，经用户指正重采全片）。
> 用途：所有视频/封面产物的质量底线。判断一个画面"素不素"，对照本表。
> 反面教材：deck-video v1（PPT 整页位图 + 页间溶解）。

## 一、视觉层（每一帧单独截图都要成立）

| # | 规则 | 标杆片表现 |
|---|---|---|
| V1 | **双族背景，按内容切换**：浅色杂志风（暖米白 #F5F1E8 级）给叙事/内容页，深色科技蓝（#0a0e1a 级微渐变）给数字/科技页；**背景干净**（纯色或极微渐变，无装饰粒子），同一场景内不变，全片不共用一个底 | 21s/278s 米白杂志页；开场/数据/结尾深蓝页 |
| V2 | **主体 = 内容的具象化**：每个场景的主体由该场景讲什么决定——对话场景用手机聊天回放、代码用终端窗、数据用图表、概念用插画/发光体；**不重复借用同一个装饰当主体** | 手机 mockup、终端、柱状图、机器人插画、地图节点 |
| V3 | **杂志式排版**：眉题小字（英文小标签）→ 超大加粗标题 + 关键词强调（每屏 ≤2 处）→ 弱化副文案；细分隔线 + 章节编号（01/02）；**非对称双栏网格**（如左文 55% 右主体 45%），留白是设计的一部分 | 左眉题+三行大字+右手机；左标题+右插画 |
| V4 | **层次**：背景 → 主体 → 文字/标注，三层分明；深色场景可加轻微暗角聚焦 | — |

## 二、动效层（时间轴上必须持续发生的事）

| # | 规则 | 标杆片表现 |
|---|---|---|
| M1 | **进场编排**：场景内按 背景 → 主体（缩放/滑入，spring）→ 文字逐行错峰（80-120ms）→ 标注最后 的顺序分层进场 | 开场：黑场→光晕绽放→行星浮现→标题逐行→关键词脉冲 |
| M2 | **微叙事**：场景内部持续有小事件——代码逐行打字、聊天气泡逐个弹出、折线生长、柱条长高、数字滚动；事件密度 0.5-2s 一个 | 对话回放、终端打字、柱状图错峰长高 |
| M3 | **进完场不是死画**：主体轻微漂浮（±8px 级 sin）、光晕呼吸、可交互元素待机微动——幅度克制，背景保持干净 | 主体漂浮、球体呼吸 |
| M4 | **转场干脆**：场景切换 0.3-0.5s 滑动/推近+淡出；单场景靠内部事件撑 12-20s，不是一屏死画摆十几秒 | 14 场 / 409s |
| M5 | **页间硬切为底（成片引擎律）**：页与页之间不叠时长、不交叉溶解，旧页末帧冻结退场，新页第 0 帧即带进场动词；动词全部发生在页内内容层，相邻页动词不同型（滑入/生长/残影/揭示轮换）；`fade()` 全片禁用（末页收黑唯一例外） | MG 武器库 S2 起（lekao 全片 3287 帧引擎） |
| M6 | **旁白同步**：字幕段 start ±0.3s 内，该段讲到的元素必须到场（进场批次锚定字幕时间轴，不锚绝对时间）；页首 2.5-3s 内 3-5 个进场批次、批间隔 0.3-0.8s | v4 律吸收，S6 P7 实测（0.00/0.40/0.90/4.50/8.31 六批） |
| M7 | **待机慢推**：页长 >10s 必给整页匀速慢推（0.3-0.5%/s），配合颗粒场/呼吸做「进行时」证据；短页不加（推不完一个弧度反而抖） | v4 律吸收，S6 P7（13.22s 页 × 0.4%/s） |

## 三、动效参数基准（Remotion 实现参考）

- 元素进场：spring `{damping: 200, stiffness: 120, mass: 1}`，0.4-0.6s 内到位
- 位移入场：起点 `y+24~32px` 或 `scale 0.92→1`，透明度 0→1 同步
- 错峰（stagger）：兄弟元素间隔 80-120ms
- 数字滚动：0.8-1.2s，ease-out
- 折线/柱条生长：1-1.5s，柱条错峰 100ms
- 待机漂浮：`sin(t/period)×8px`，period 3-5s，各元素相位错开
- **确定性铁律**：渲染函数内禁 `Math.random()` / `Date.now()` / `new Date()`（破坏 Remotion 确定性渲染），一律用索引伪随机（如 `(i * 137) % 100`）

## 三.B、MG 武器参数基准（S2-S6 实测，武器本体见 component-catalog）

| 场景 | 参数 | 出处 |
|---|---|---|
| 整组滑入 | direction left、distance 0.33×画宽、dur 0.35s | SlideGroup 默认 |
| 级联列表 | stepMs 280（「数得出来」的节奏，≠ StaggerList 110-150ms 的瞬间落位档） | CascadeList 默认 |
| 下划线/引线生长 | dur 0.6s、endDot、strokeWidth 6-8；深底用品牌蓝提亮档 | DrawPath |
| 进场残影 | layers 8 / lag 2 / trailOpacity 0.36；柱图/卡片级元素用，重子树（视频/大 SVG）慎用 | BlurTrail |
| 慢推 | ratePerSec 0.004（0.4%/s），页长 >10s 才给 | CameraPush |
| 标题呼吸 | ±1.2-1.5% / 3s，落位后 0.8-0.9s 起 | TextBreath |
| 颗粒场 | dark opacity 0.28 / light 0.32，seed 固定数字 | NoiseField |
| **transform 包装坑** | 一切带 transform 的包装动词（CameraPush/SlideGroup/TextBreath/BlurTrail）不得直接包 position:absolute 子树——transform 元素是 absolute 后代的 containing block，流内高度被塌成 0，布局顶格溢出；组件内自足（CameraPush 根 inset 0、BlurTrail 主层流内），用法上仍避免在 absolute 父级里裸包 | S6 双坑实录 |

## 三.5、质感层（v3 增补：v2 成片审图教训——"会动的 PPT"仍是 PPT）

| # | 规则 | 反例（审图实录） |
|---|---|---|
| F1 | **光影成体系**：每个悬浮元素双层阴影（环境光+接触/主投影）+ 1px 边光（深底上 rim light，浅底上 hairline 描边）；背景是"空间"不是"色板"（浅族：底色+极淡网格+角落柔光斑；深族：径向渐变+暗角+微噪点）；同类元素共享同一光源方向 | 卡片无投影"贴上去的色块"；深底纯平无纵深，元素像贴纸 |
| F2 | **道具经得起放大**：拟物道具（设备框/终端/聊天/图表）凑近看不能穿帮——真 chrome 细节（标签页、侧键、灵动岛贴顶、锁形图标）、真字体（终端等宽、气泡无衬线）、真结构（图表有基线网格线）；截图文本缩小后不可读时必须改滚动展示或裁切特写 | 浏览器无标签页"画了个浏览器"；手机无侧键灵动岛错位；气泡内衬线字瞬间出戏；长图塞进手机 60% 死灰 |
| F3 | **无死空间**：单块零信息区域不得超过画面 20%；主体之外要有次级内容填格（批注、箭头、元信息、进度指示），留白是呼吸不是空旷 | 页面中部 400px 真空带、三分之一画面零信息 |
| F4 | **版面一体**：字幕是版面的一部分，用画面同一套设计语言（同字体/同色调/同圆角），不贴"黑药丸"；画面已有的大字与字幕重复时字幕让路（去重）；任何元素不得与字幕区/其他元素无序叠压 | 黑底字幕条被逐页点名"廉价感第一"；同一句话页内出现两次 |
| F5 | **信息自足（静音测试）**：关掉声音只看画面，观众能说出这一页在讲什么——每页除主标题外必须有 ≥2 组实打实的支撑信息（数字、步骤、事实）和 ≥1 层主体标注；支撑内容只能来自真实素材，禁止编造 | 全片靠底部字幕硬扛信息量，画面只剩"一句文案+一个道具" |

## 四、判断口诀

一屏画面问八句：**背景选对族了吗（V1）？主体是内容本身吗（V2）？排版像杂志吗（V3）？现在动吗（M3）？有光影吗（F1）？道具经得起放大吗（F2）？有死空间吗（F3）？静音能看懂吗（F5）？** 八问全过才不是"素"。终极一票否决：**这一帧放进 PPT 里违和吗？不违和 = 打回**（好视频帧应该"满、深、活"到 PPT 装不下）。
