# 动效语法（Motion Grammar）— 从标杆片拆解的通用规则

> 来源：Claude 逐帧拆解 B 站标杆片 BV1fShG6LETU（《为什么 AI 越来越强…Agent 实战》，6'49"，1080p30，17.5 万播放），2026-08-30。
> 采样方法：14 个场景转场点切 15 段、每段抽稳定帧全片覆盖 + 4 段密集抽帧看进场动画（v2 修订：初版曾以开场行星段概括全片，经用户指正重采全片）。
> 用途：所有视频/封面产物的质量底线。判断一个画面"素不素"，对照本表。
> 反面教材：deck-video v1（PPT 整页位图 + 页间溶解）。

## 一、视觉层（每一帧单独截图都要成立）

| # | 规则 | 标杆片表现 |
|---|---|---|
| V1 | **双族背景，按内容切换**：浅色杂志风（暖米白 #F5F1E8 级）给叙事/内容页，深色科技蓝（#0a0e1a 级微渐变）给数字/科技页；**背景干净**（纯色或极微渐变，无装饰粒子），同一场景内不变，全片不共用一个底 | 21s/278s 米白杂志页；开场/数据/结尾深蓝页 |
| V2 | **主体 = 内容的具象化**：每个场景的主体由该场景讲什么决定——对话场景用手机聊天回放、代码用终端窗、数据用图表、概念用插画/发光体；**不重复借用同一个装饰当主体** | 手机 mockup、终端、柱状图、机器人插画、地图节点 |
| V3 | **杂志式排版**：眉题小字（英文小标签）→ 超大加粗标题 + 关键词强调（每屏 ≤2 处）→ 弱化副文案；细分隔线 + 章节编号（01/02）；**非对称双栏网格**（如左文 55% 右主体 45%），留白是设计的一部分 | 左眉题+三行大字+右手机；左标题+右插画 |
| V4 | **层次**：背景 → 主体 → 文字/标注，三层分明；深色场景可加轻微暗角聚焦 | — |

## 二、动效层（时间轴上必须持续发生的事）

| # | 规则 | 标杆片表现 |
|---|---|---|
| M1 | **进场编排**：场景内按 背景 → 主体（缩放/滑入，spring）→ 文字逐行错峰（80-120ms）→ 标注最后 的顺序分层进场 | 开场：黑场→光晕绽放→行星浮现→标题逐行→关键词脉冲 |
| M2 | **微叙事**：场景内部持续有小事件——代码逐行打字、聊天气泡逐个弹出、折线生长、柱条长高、数字滚动；事件密度 0.5-2s 一个 | 对话回放、终端打字、柱状图错峰长高 |
| M3 | **进完场不是死画**：主体轻微漂浮（±8px 级 sin）、光晕呼吸、可交互元素待机微动——幅度克制，背景保持干净 | 主体漂浮、球体呼吸 |
| M4 | **转场干脆**：场景切换 0.3-0.5s 滑动/推近+淡出；单场景靠内部事件撑 12-20s，不是一屏死画摆十几秒 | 14 场 / 409s |

## 三、动效参数基准（Remotion 实现参考）

- 元素进场：spring `{damping: 200, stiffness: 120, mass: 1}`，0.4-0.6s 内到位
- 位移入场：起点 `y+24~32px` 或 `scale 0.92→1`，透明度 0→1 同步
- 错峰（stagger）：兄弟元素间隔 80-120ms
- 数字滚动：0.8-1.2s，ease-out
- 折线/柱条生长：1-1.5s，柱条错峰 100ms
- 待机漂浮：`sin(t/period)×8px`，period 3-5s，各元素相位错开
- **确定性铁律**：渲染函数内禁 `Math.random()` / `Date.now()` / `new Date()`（破坏 Remotion 确定性渲染），一律用索引伪随机（如 `(i * 137) % 100`）

## 四、判断口诀

一屏画面问四句：**背景选对族了吗（V1）？主体是内容本身吗（V2）？排版像杂志吗（V3）？现在动吗（M3）？** 四问全过才不是"素"。
