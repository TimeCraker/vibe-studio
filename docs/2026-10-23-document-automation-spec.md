# 文档自动维护工具

## 目标与边界

把目录、技能、命令等确定事实从手写说明中移出；按 Git 变化定位可能失效的文字，由当前编程 Agent 直接修订现有说明。提供 workspace 本地检索，不复制一套项目知识，不新增数据库、服务或模型调用。

工具正本在 vibe-studio，可用 --repo 操作其他仓库；workspace 接入只添加共享入口和可兼容的本地 Git 检查，不批量改写其他项目业务说明、旧计划或历史验收。索引是可重建缓存，检索结果给出源文件/版本与未核对状态，不能推断人工接受、上线或发布。

## 验收标准

- 受管生成块之外的内容逐字保留；技能/目录/命令变化可以更新生成块，重复运行不产生差异。
- CLI 帮助与命令表使用同一声明；检查支持 Git 暂存区，不用工作区文件冒充本次提交。
- 影响定位覆盖代码路径、目录、命令引用与删除/改名；给出来源和候选文档，不把候选写成已确认过期。
- 新增坏链接和生成块漂移可拦截提交；旧问题与语义疑点不无差别阻塞。钩子不自动暂存或覆盖现有钩子。
- 索引只读取限定文档，不跟随链接，不读凭证或缓存；支持中文/英文检索、历史区分和源内容变化后的刷新。
- workspace 接入后可真实查询多个仓库；其他仓库已有改动与钩子保持原样。复杂语义修订复用当前 Agent，不增加按提交调用付费模型的依赖。
