# 每日 AI 资讯栏目 Stage Spec（方案草案）

方案核对日期：2026-10-23，时区 Asia/Shanghai；制作状态更新于 2026-10-24。栏目规划、流程草案和参考图已有。用户已否定首期后来生成的 65 秒无声版，现有独立 62 秒重制版待审，实际版本与证据见第 12 节；技术通过不能覆盖用户的否定。没有上传，采集适配、正式 TTS 和日更续跑还没有验证。

用户确定纸白＋珊瑚色的瑞士报刊风，并最新明确榜单优先参考其提供的“左侧前三名、右侧第 4 至 15 名”截图，原有本地图片全部保留为辅助。排斥的是浅底上的黑色图标方块及黑底流程卡，不包括冠军珊瑚色块和细线方形卡片。用户要求停止继续生图，日常生产用 vibe-studio 现有制作能力实现。画幅候选为 16:9 或 4:3，首个代码样片用 16:9，保留 4:3 排版适配；每张画面独立，不拼成长图。首期与日更的帧率确定为原生 60fps。新闻条数、板块数量与片长均随当期内容价值决定，不设配额；合理检索核实后没有合适资讯可以不出片。正式配音和平台策略仍待样片验证，竖版精选后续按需增加。

## 1. 目标与自动化边界

目标：每天调用一次项目内的 [daily-ai-news](../skills/daily-ai-news/SKILL.md)，先完成资料检索、筛选核查和是否出片的判断。有值得报道的内容时再完成榜单快照、口播/字幕、素材、模板渲染、技术检查和投稿物料，并按既有授权辅助上传填表；没有合适资讯时保留选题结论即可。现有入口是供 Agent 执行的流程草案，不代表确定性采集和自动成片已经跑通；首期也先按[接手任务](2026-10-23-daily-ai-news-cursor-prompt.md)判断选题，再决定是否试制。

沿用[制作流程](../workflows/explainer-video.md)：首次确定栏目与代表样片，日常复用已接受的系列方案。每期不重新询问已确认的颜色、字体、常规版式或已授权范围。新增收费服务、重要方向变更与来源异常单独处理。

人仍负责实际需要的录音、内容/视听终审、登录及最后点击发布。无人审阅时自动交付待审稿，不记录成人工接受。每日调用与定时无人值守执行是两个范围，本阶段不创建定时任务。

每期按新闻价值和叙事重点取舍，条数和时长都没有固定配额。有价值的新闻多时，用头条、次重点、简讯或专题组织，相关事件合并，重点深入，其余精炼；保持主次和观看质量。有价值的新闻少时可做短刊；只有一条但足以支撑独立内容，也可做单主题片。

合理检索核实后没有合适内容，就记录“今日不出片”，保留查阅来源、主要候选与淘汰原因，作为正常完成结果，不进入配音、渲染和投稿物料制作。检索失败、来源不可读或核实不足要记录为受阻/待核实，不能冒称已筛选完但当日无新闻。

## 3. 每日生产链

| 阶段 | 自动执行的工作 | 留下的输入或结果 |
|---|---|---|
| 建立本期 | 读取已确认栏目方案、最近一期与当前日期；建立或续跑选题记录 | 本期日期、系列版本、时间窗口 |
| 检索 | 查询官方公告、博客、文档、GitHub 发布与可靠媒体；从参考文档提取候选线索 | 候选、链接、事件时间、发布时间、取得时间 |
| 去重和核查 | 按事件合并转载；核对原始材料、数字单位、可用地区/入口、官方声明与独立结果 | sources 及 storyboard claims |
| 筛选与出片判断 | 按价值排序并决定是否出片；出片时确定主次和篇幅，不出片时结束下游制作 | 本期选题或不出片结论、候选分数、主要淘汰原因 |
| 榜单 | 读取指定站点本次公开页面/快照，核对 ECI 口径，取原榜前 15 名 | 原始证据、ranking 快照、比较结果 |
| 稿件与分镜 | AI 写口语稿并润色，逐段绑定画面和事实；主新闻解释具体变化与用途 | script、storyboard、读音说明 |
| 配音与字幕 | 按选定模式取得实际音轨，再转写/对齐并纠正模型名等专有词 | 分段音轨、实际时长、SRT/cues |
| 画面与封面 | 加载本地素材和快照，用栏目组件生成榜单、新闻、解释页与封面候选 | 实际代表帧、短样片、正式渲染 |
| 检查与返修 | 内容/数据检查、media-qc、实际看图及可用范围内的视听检查；仅重跑受影响步骤 | QC、绑定版本的审稿观察、待审项 |
| 投稿与保全 | 平台文案、来源署名、封面、预检；按授权填表；归档并验证可恢复 | 投稿状态、交付清单、recipe、archive.json |

榜单及后续阶段仅在决定出片后执行；此时才初始化或续跑制作工程并补 brief、job 等契约。不出片时保留必要的选题证据，不要求创建空视频工程，也不为播放榜单而凑一期。

首次检索默认回看最近 24 小时，必要时延伸到 48 小时找遗漏并标清日期。稳定日更后，从上一成功期的截止点接到本期截止点，避免漏掉隔日新闻；原始时区和北京时间同时保留。最近约 7 天已报道事件只在有明确新进展时再讲。

稿件采用“发生了什么 → 对谁有用 → 与原来相比有什么变化 → 怎么用/有哪些限制”。实测、官方宣称与推测分开写；不能把“官方称提升”改成“我们验证提升”。

候选进入正式稿前必须有可读取、能支撑结论的证据；该条件不靠高分抵消。通过后按受众相关性 30、变化重要性 25、实际用途 25、新鲜度 20 评分，分数用于排序和解释，不当作客观真理。封面主新闻另看模型话题强度和可兑现的观看承诺，不自动选择最夸张的标题。

## 4. 开场榜单

指定入口：[B 站 AI 大模型世界](https://www.bilibili.com/toy/ai-model-world)。当前页面内嵌的排行榜将“综合智力”说明为 Epoch Capabilities Index；[Epoch 官方说明](https://epoch.ai/eci)将它定义为多项评测综合出的通用能力尺度。因此片中标题建议为“AI 模型综合智力 TOP 15”，副标明确 ECI，而非声称覆盖全部实际任务的绝对能力。

读取方案：每次从 B 站入口发现当时内嵌页面，不写死此次含版本号的路径。优先读取公开且有依据的结构化数据；不能取得时解析本次公开榜单并保存证据。该站[开源仓库](https://github.com/liyupi/ai-model-world)的 `data/models.json` 有生成时间、来源时间和模型 id，可供核对或明确标明的后备来源；仓库快照可能早于或晚于已部署页面，不静默当作同一份数据。

数据规则：

- 保留来源名称、ECI 口径、原榜位置、模型 id/名称、分数、来源更新时间、抓取时间和证据哈希；抓取时间不能冒充数据更新时间。
- 保留原榜的过滤条件、并列与排序行为。不同模型版本和思考配置不按展示名称强行合并；同名记录要核对 id，缺少可区分信息时标记待核对。
- ECI 是指数，不写成百分数，不与编程、价格或其他榜单求平均；没有成绩的模型不补分上榜。
- 只有与上一份同口径、同过滤条件的有效快照比较，才显示升降；首次取得数据或方法变化时不显示虚假的“较昨日上升”。
- 榜单未变就直说未变；数据取得失败时保留待补采，或按事先约定显示明确日期的旧快照，不能标成今日排名。必需榜单缺失时不宣布完整交付。

版式建议：开场约 15–25 秒；先给完整 TOP15，再聚焦前三名或真实变化。完整画面使用“左侧前三名重点区 + 右侧第 4–15 名紧凑列表”，保留可暂停阅读的停留。9:16 版本改为每屏 5 名，绝不整表缩小塞入竖屏。旁白只解读有价值的变化，不逐个念 15 个名字。

## 5. 配音决策与字幕

AI 负责稿件是默认方案，是否真人朗读独立选择。推荐先做同一段约 30–45 秒的全 TTS / 混合配音试听，比较自然度、术语读音、信息理解与用户实际耗时，再定每日默认。

| 模式 | 用户每天的参与 | 制作影响 |
|---|---|---|
| 全 TTS | 审听和终审 | 自动化程度最高；需实测音色、术语、停顿和生成费用 |
| 混合（建议先试） | 录约 15–30 秒开场/个人判断，其余由 TTS 完成 | 保留个人声音，录音时长可控；统一音量和段落衔接 |
| 全真人 | 通读全稿，分段录音，按需补录 | 个人表达空间更大；每日投入取决于熟练度与返工 |

目前 narration 负责分段稿，正式语音依赖人工剪映；audio-post 不生成语音。仓库 SAPI 测试音轨仅供管线预览，不等于正式 TTS 质量。要实现全 TTS 或混合模式，必须新增实际可用的语音适配，并相应调整本栏目涉及的 narration 交接说明；服务商、音色、费用和凭证方式在试听前明确，不预先采购、创建密钥或调用收费接口。

不要求逐字背稿。若选真人，先读顺术语与停顿、分段录制；脚本同时提供发音和重音提示。最终音轨决定镜头时长。字幕从这份音轨转写/对齐，再以已核实稿件校正专有词；不能把字数平均摊时当作精确同步，也不能把口播稿直接粘上去就声称已对齐。

## 6. 已选美术与预览范围

参考已核对的 `coding-plan-bench/site/src/styles/globals.css` 与用户最新截图：纸感底 `#f3f2ed`、墨色 `#1a1a18`、珊瑚 `#a8513c`，以粗黑标题、网格、细线方框、留白与等宽数字建立报刊层级。榜单以[用户首选截图](../skills/daily-ai-news/assets/style-reference/ranking-preferred.png)为主要依据，其他图片保留辅助。第一名可用珊瑚实底白字，二三名可用纸白细线卡片；不照搬新闻示意里的黑底图标板和黑底流程卡。纸堆、自然光和摄影感只作辅助，不替代瑞士报刊排版。官方图标按原文件显示，中文字体、模型英文名和数字在实际渲染环境固定。参考优先级和适用范围统一见[视觉约定](../skills/daily-ai-news/references/visual-style.md)。

先讨论三种同家族封面构图：

| 封面构图 | 画面 | 适用新闻 |
|---|---|---|
| C1 头版大字 | 巨型主标题、单个官方标志、短副标题，栏目名与日期有固定位置 | 旗舰模型发布、重大更新；建议默认 |
| C2 双主体比较 | 两个官方标志和具体比较维度，正文有依据才放数字 | 确有同口径数据的模型比较、价格变化 |
| C3 证据特写 | 产品官方截图或图表为主体，旁边只写一个关键结论 | 新能力、新交互、重大开源产品 |

视觉方向已获用户认可，不再补生成式预览图。此前的生成图仅用于确认颜色、排版气质和轻重关系，不能当作日常生产素材或真实新闻证据。封面构图、新闻正文和完整 TOP15 后续直接用代码做代表帧/短样片，核对实际字体、信息密度、画幅、字幕与动效；风格认可不等于这些实现已通过验收。样稿中的示意标题和占位数字不能被误当作当日事实。

正式封面和片中标志使用官方品牌文件。模型没有独立标志时，使用其所属产品/厂商官方标志加准确模型名，不臆造“模型 logo”。本轮已取得适合浅底的[OpenAI 官方黑色标志](https://github.com/openai/openai-agents-js/blob/main/docs/public/favicon.svg)作为参考；后续逐个保存原文件与来源，按[官方品牌说明](https://openai.com/brand/)核对使用形式，不把 AI 重绘当作官标。该官方 favicon 带白色圆形底；正式排版若需要完全透明版本，另取官方对应文件，不添加黑色底板。

新闻页用“短标题 + 真实相关图片/截图 + 一个重点 + 一句影响”；需要解释数据时换为比较图/流程图。图片优先官方公告素材、产品截图和发布演示，缺少相关图片时用有来源的数据排版，不用不相关的机器人图片装饰。asset-scout 记录实际文件、来源、使用条件与署名，不能把候选网址写成已取得的素材。

动效方向：榜单按行显现并聚焦变化，图片做克制的平移/推近，关键数字定点出现，切换使用短距离滑入或直接切换。稳定阅读时间优先于持续运动；不制造无数据依据的名次竞争动画。图片预览确定版式后，另做短样片判断速度和声音，静图通过不等于动效通过。

## 7. 技术实现与技能职责

主线选 B：复用锁定版本的 Remotion 模板。Remotion 的画面本来就是 React、HTML/CSS 和 SVG；模板组件根据当前帧绘制画面，再编码成视频。封面使用同一套组件渲染静帧，日期、标题、图片、模型标志和排名由本期数据驱动，日常不需要重新手写页面。

视觉实现不引入生图环节：

| 视觉要素 | 现有制作链中的实现 |
|---|---|
| 纸白底、文字、细线、珊瑚强调 | 本地字体、CSS/SVG 和固定设计参数 |
| 纸页层次与轻阴影 | 少量矩形图层、轻微旋转、边缘高光与柔和阴影；不承诺复刻生成图里的摄影级纸纹和自然光 |
| 模型/厂商标志 | 读取官方 SVG/PNG 原文件，按本期素材清单固定版本 |
| 新闻图片与演示 | 官方配图、真实截图/录像；没有合适素材时使用有来源的文字、数字和图解 |
| TOP15、价格/能力对比 | 本期已核实 JSON 驱动现有图形组件或栏目内的简单排版组件 |
| 字幕、转场与镜头运动 | 复用字幕/动效组件，时序由帧号与实际音轨驱动 |
| 视频与封面 | 现有 Remotion render / still；已有本地 HTML 素材按需走 C 线 |

代码画布使用明确的整数尺寸：16:9 采用 1920×1080，4:3 可采用 1600×1200，均从实际 Composition 和时间轴按 60fps 渲染；参数生成器、总帧数、字幕/动效的秒帧换算须一致，音轨和镜头时长不变。不得仅靠后期复制帧转码达到 60fps。图像预览的近似比例、分辨率和长图结构不是输出规格；数据布局按画幅重排，不拉伸。

需要开发的是栏目模板、检索/榜单适配与轻量编排，而非新的图像生成系统。现有仓库尚未具备正式自动 TTS，因此“视觉不依赖生图”不能被写成“现有工具已能无人值守完成配音和发布”。

C 线保留给已有本地 HTML/SVG 或需要采集的页面素材；线上真实产品截图/录像按实际工具取得。没有必要为了这个栏目另起网站、数据库、长期服务或通用 Agent 框架，也不强制把视频先做成 PPT。渲染前下载/固定已选输入；渲染过程不实时请求资讯站、图标或榜单，防止同一期前后不一致。

已新增薄的栏目入口 daily-ai-news，正本在 skills 下的同名目录，保留流程草案及[本地视觉参考](../skills/daily-ai-news/references/visual-style.md)。它串联 content-director、narration、humanizer、asset-scout、video-motion、audio-post、auto-subtitle、media-qc、publish；确定性抓取、校验和渲染由首期执行 Agent 实作，不复制这些技能的完整规则。首次样片稳定后才提取实际复用的代码模板；参考图只用于风格，不直接作为成片整页输入。
