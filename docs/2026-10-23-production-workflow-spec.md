## 目标与边界

保留 Python / Remotion / FFmpeg / Chrome 三条制作线，补全可复跑归档、确定性采集、轻量编排、导演设计、媒体质检、平台派生与效果复盘。原片源码、字幕、发布配置可以从当前工作树恢复；缓存与大媒体不混入 Git。人工配音、终审、登录、点击发布继续保留。

## 验收标准

- 归档保留制作配方与素材哈希；恢复后源文件逐字节一致；缺素材明确报告；校验未通过禁止清场。历史作品按可获得证据恢复，缺失项明确登记。
- rAF 一次推进只执行本帧队列；有状态动画分块必须从零预跑，显式 seek 页面可直接定位；顺序与分块采集有真实浏览器回归。
- CDP 断连/错误/超时会结束未完成请求；采集 worker 超时可退出；发布 dry-run 传播失败，调度可选基础与 Playwright 层。
- C 线包含可运行的网页、镜头表、导演页、时间轴、封面和音频网格样例；从模板能够完成真实视频渲染。
- CLI 支持初始化、环境诊断、配置校验、步骤缓存与失败续跑、归档与恢复；输入/输出变化会使缓存失效，不把人工审核标成机器通过。
- 导演、平台派生、复盘 skill 有可验证数据契约与工具；质检输出机器报告、抽帧证据与待人工项目，不伪造质量或运营结果。
- 视觉规则按内容类型选择；短样片前置；横竖版、封面和来源证据在策划时确定。
- skill 入口与 README、产品图、工作流、文档检查器保持一致；官方 Remotion 参考固定来源版本，不自动升级渲染依赖。
