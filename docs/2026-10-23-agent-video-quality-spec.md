# Agent 视频质量流程整理

目标：减少技能入口重叠，打通参考分析、动态分镜、正式制作、声音后期和基于实际媒体的审稿返修。沿用现有工程、工具和发布授权边界；不接入新付费服务或改写历史作品。

进度（4/5）：

- [x] S1：将平台适配和发布复盘合入 publish，按准备/投稿/复盘按需加载，更新现行调用与技能发现。
- [x] S2：实现 audio-post：配置驱动的音轨编排、音乐避让、混音和响度处理，保存输入与输出证据。
- [x] S3：实现动态分镜：复用 storyboard 时间，参考图与临时音轨生成可播放粗样片，明确预览身份。
- [x] S4：补齐参考片分析、视觉方向、事实核查、带时间码的视听审稿及局部返修方法，同步入口与流程。
- [ ] S5：完成媒体正负例、原有测试、真实粗样片与混音检查、文档/技能校验，并提交。

验收：10 个内容技能入口；原有 derive/review/publish 能力保留；新工具真实产生可解码的媒体且时长符合契约；音乐避让和响度处理由实际信号验证；粗样片使用既有分镜时间并绑定源哈希；审稿记录绑定实际媒体版本，技术通过不冒充人工接受。无素材/无工具时如实报告，不生成虚构审稿、来源或运营数据。

发布合并保留模块边界与旧 CLI 命令；直接技能脚本路径迁入 publish，历史 recipe 不迁移。声音后期支持真人录音和 TTS 输出，不负责获取配音。动态分镜与新增处理步骤均按需调用，不强制加入所有旧 job.json。

可选生成式镜头、地图专项等只留选用指引，不新增重复技能、不下载模型、不产生在线费用。实际画面/声音的人工接受保留待审状态。

回归中发现既有 Chrome 固定调试端口可能连接到旧实例、导致截图超时，已改为默认独立端口并校验本次启动的端点；显式占用端口拒绝连接，不接管或关闭已有用户浏览器。
