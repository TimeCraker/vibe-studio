## 已落地

- README 的技能、目录、CLI 命令和运行/渲染版本由配置与代码生成；生产 CLI 帮助与命令表使用 scripts/studio-commands.json。生成区外文字保留，重复运行无差异。
- docs.mjs 提供 maintain/sync/check/impact/guard/index/search/hooks/setup。维护入口只自动改确定生成区，语义修订交给当前编程 Agent；不引入模型 API、服务、数据库或逐次台账。
- 变更影响从 Git diff、路径、目录与命令引用定位，支持删除/改名及未映射行为的提示。Git 暂存区与工作区分开读取，不以全量暂存规避部分提交。
- 19 个非归档仓库接入提交检查：16 个本地独立钩子，3 个兼容的既有 Husky 脚本追加检查。保留原始检查、失败码和已有业务改动；无自动暂存。归档仓库排除，试接入的归档钩子已移除。
- workspace 根 AGENTS 添加共享维护与检索入口；CLAUDE 原有入口会指向它。新增 doc-maintainer skill，正本与项目本地发现链接已安装，没有修改全局 Codex 配置。
- 索引覆盖 19 个仓库和约 470 份限定文档（含 workspace 根入口，数量随其他项目改动变化）。缓存只存词项、标题、路径、哈希和引用；检索重读来源，区分历史与待核对提示。

## 验收边界

索引不是向量问答；候选和 needs-review 是核对线索，current 只表示未按历史规则归档，不是语义已确认。工具不能从代码推断业务意图、人工美术接受、真实发布或生产上线。

其他项目的历史说明没有被批量改写，新的自动生成块也未强制铺到所有仓库；共享检查与检索已接入，具体生成区可在确有重复清单的项目按需采用。现有项目继续使用自己的计划和规则。

本轮未运行远程 CI、付费 API、真实投稿或生产部署；未重做视频/美术验收。CI 已加确定文档检查，本地测试与干净克隆的通过仅代表上述范围。
