Tageszusammenfassung - 27.10.2026

End-of-Day report

Timeframe: Freitag 23-10-2026 18:00 - Dienstag 27-10-2026 18:00 Handler: Katharina Siess Co-Handler: Guenes Holler

News

Broccoli2shell: Everything You Need To Know About The Critical Brotli Decoder Vulnerability

A critical vulnerability, tracked as CVE-2026-111497 and referred to as Broccoli2Shell, has been identified in the Brotli decompression library. The vulnerability affects multiple widely used technologies, including Node.js, Bun, Envoy Proxy, and more. Successful exploitation could allow an unauthenticated remote attacker to trigger memory corruption, disclose sensitive information, crash affected processes, or potentially achieve remote code execution (RCE). Organizations using affected components to decompress untrusted Brotli-compressed data are advised to prioritize remediation.

https://www.wiz.io/blog/cve-2026-111497-brotli-rce-node-js

PHP2Shell security flaws now sucessfully exploited in the wild

Two critical RCE vulnerabilities (CVE-2026-109618 and CVE-2026-109619), collectively tracked as PHP2Shell, have been successfully exploited in the wild.

https://www.bleepingcomputer.com/news/security/php2shell-security-flaws-now-sucessfully-exploited-in-the-wild/

Das Wohnungsinserat als Einfallstor für Schadsoftware

Der Immobilienmarkt ist angespannt. Stolpert man zufällig über eine leistbare Wohnung in guter Umgebung, soll es nach Möglichkeit entsprechend schnell gehen. Kontaktaufnahme, Besichtigungstermin, Unterschrift. Eine Situation, in der Menschen eventuell unvorsichtiger reagieren als sonst. Und genau darauf setzen die Kriminellen. Sie nutzen diese positive Aufregung, um über ein Formular Schadsoftware auf die Endgeräte ihrer Opfer zu schleusen.

https://www.watchlist-internet.at/news/wohnungsinserat-einfallstor-schadsoftware/

Vulnerabilities

Microsoft releases emergency .NET patches for critical Brotli flaw

Microsoft released emergency .NET security updates to patch a critical vulnerability known as Broccoli2Shell, also tracked as Node2Shell and HTTP2Shell. Tracked as CVE-2026-111497, this critical-severity flaw stems from an out-of-bounds write in the Brotli decoder, which expands data compressed using Google's widely used Brotli lossless compression algorithm.

https://www.bleepingcomputer.com/news/microsoft/microsoft-releases-emergency-net-patches-for-critical-brotli-flaw/

Two Critical Wasmtime Flaws Could Let Malicious WebAssembly Modules Escape Sandboxes

Two critical flaws in Wasmtime, a WebAssembly runtime that can be built into other software, could allow a malicious WebAssembly module to escape the sandbox intended to contain it, the project's maintainers say. An attacker would first need a vulnerable Wasmtime build to compile a module they control, and one of the flaws affects only ARM64 systems. Fixed versions were released on October 19 and 20, and the maintainers have not reported any attacks.

https://thehackernews.com/2026/10/two-critical-wasmtime-flaws-could-let.html

Microsoft Authenticator Flaw Let Permissionless Android Apps Steal Work Account Tokens

Microsoft has fixed a flaw in its Authenticator app for Android that let a malicious app with no permissions pose as a trusted Microsoft app, such as Teams, and collect sign-in tokens for a victim's work account. Microsoft tracks the flaw as CVE-2026-80097 and fixed it in Authenticator for Android version 6.2606.4246, so anyone using the app should update.

https://thehackernews.com/2026/10/microsoft-authenticator-flaw-let.html

Apple Backports Fix for Exploited CoreGraphics Flaw to Older iPhones and iPads

Apple on Monday backported fixes for a high-severity security flaw that was exploited in real-world cyber attacks to older devices. The vulnerability, tracked as CVE-2026-86950 (CVSS score: 8.8), is an out-of-bounds write affecting CoreGraphics that could result in arbitrary code execution when processing a maliciously crafted file.

https://thehackernews.com/2026/10/apple-backports-fix-for-exploited.html

Python schließt per Update kritische TLS-Lücke wegen eMudhra-Schlüsseln

Python 3.15.2, 3.14.10, 3.13.18, 3.12.16 und 3.11.18 beheben eine kritische Schwachstelle durch kompromittierte eMudhra-Zertifikate und weitere Lücken.
