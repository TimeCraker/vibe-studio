# 美术资产库（art/）

SVG 插画与 AI 出图的家底——需要插画的镜头的美术载体（消费组件：scene-kit ArtLayer）。当前选材按 docs/2026-08-30-motion-grammar.md，导演与生图简报见 content-director；真实操作、截图和结构图使用适合的原生载体。

**施工装载**：在研项目施工期间，将所需图复制进临时施工工程 `remotion-app/public/art/`，渲染时 `ArtLayer src="art/<文件名>"`（src 是 public/ 相对路径）；程序化 SVG 也可内联字符串直传 `svg` prop（零 IO，模板 demo 同款）。本目录只收录有共用价值的资产；项目专用图及其来源先留在项目中，边界见[资产库说明](../README.md#项目专用与共用素材)。

## 收录铁律

1. **只收可商用**：AI 出图须确认生成平台的商用条款；素材站看许可证标注，拿不准的坚决不收
2. **按实际取景核对清晰度**：以画面占比、裁切和最大放大比例检查有效分辨率；局部小道具不按整张画布尺寸硬性要求，SVG 中的位图依赖也需检查
3. **记录适配的视觉方向**：沿用本片已确定的品牌或项目背景族，质量判断见[当前规范](../../docs/2026-08-30-motion-grammar.md)，不让单个素材反向决定整片风格
4. **登记即入库**：来源 / 许可证 / 分辨率三字段齐才算收录；文件名 `kebab-case`，按用途命名（`mountain-dawn.svg` / `city-night.png`），不保留下载原名

## 生图与原始输入

生图使用当前环境提供的工具，先确认代表画面与构图，再生成同片素材。登记原始文件、工具/模型、简报或提示、日期、条款来源和 SHA-256；图上文字由排版层绘制。生成器不能替许可核查或视觉审阅作保证。

项目使用的素材必须随 archive.json 记录并备份，不能只登记 assets 的名字。截图与原始配音同样属于制作输入；清场前验证备份可恢复。
