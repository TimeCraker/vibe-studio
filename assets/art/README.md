# 美术资产库（art/）

SVG 插画与 AI 出图的家底——**画面主体的载体**（spec：`docs/2026-10-05-art-layer-spec.md`；消费组件：scene-kit `ArtLayer`）。S6 复盘根因修复：全片不能没有真正的「图」，CSS 只做排版。

**施工装载**：在研项目施工期间，将所需图复制进临时施工工程 `remotion-app/public/art/`，渲染时 `ArtLayer src="art/<文件名>"`（src 是 public/ 相对路径）；程序化 SVG 也可内联字符串直传 `svg` prop（零 IO，模板 demo 同款）。成片交付后临时工程清场，本目录资产长期保留。

## 收录铁律

1. **只收可商用**：AI 出图须确认生成平台的商用条款；素材站看许可证标注，拿不准的坚决不收
2. **分辨率 ≥ 目标画布**：源图最短边不低于成片画布对应边（4K 片不吃 1080 图；SVG 矢量天然豁免此条）
3. **风格须与项目背景族匹配**（浅米白杂志 / 深蓝科技，见 motion-grammar V1）——收录时在用途栏注明适配族
4. **登记即入库**：来源 / 许可证 / 分辨率三字段齐才算收录；文件名 `kebab-case`，按用途命名（`mountain-dawn.svg` / `city-night.png`），不保留下载原名
