v0.3.6
6f56557
  • 插话立即生效（#41）：任务进行中发的插话（插话发送、排队栏“立即发送”）马上显示在对话里，模型在当前任务的下一步就能看到，不再等这一轮结束才另开一轮。停止任务时，还没插进去的话会退回输入框
  • 悬浮球和通知能回到正在运行的对话（#39）：后台运行时点悬浮球或进度胶囊，打开的是正在运行的那个对话，不再新开对话；点通知栏的运行通知能回到 App。适配了 HyperOS 等系统对后台打开界面的限制
  • 第三方识图模型能看到图片了（#39）：之前不在内置列表里的识图模型（Gemini、GPT-4o、Qwen-VL、GLM-4V 等）会被当成纯文本模型，图片被替换成文字说明。现在按服务商接口返回的信息和模型名自动判断，模型编辑页可以手动设“图片输入”；图片发不到当前模型时，输入框会提示
  • App 内切换语言（#40）：设置 → 通用 → 语言，可选跟随系统、中文、English，Android 10–12 也能用。新增语言只需要加一份翻译文件，欢迎贡献
  • 这版没有在真机上测试过
  • 仅支持 arm64-v8a，Android 10 及以上；正式签名，可直接覆盖安装，也可以在 设置 → 关于 里直接更新

jackwener released this 30 Oct 21:12
v0.3.0
9e22d7e

插件、技能和 MCP（#17）：设置里新增“扩展”，分插件、技能、MCP 三栏。

  • 插件：用的是 dsh 自己的插件格式和插件管理器，和桌面版 dsh 装的是同一套插件。可以浏览精选列表、搜索，也可以粘贴 npm 包名、npm 或 GitHub 链接，或者选 .tgz/.zip 文件安装。插件的设置表单按插件自己声明的配置自动生成，改了立即生效。安装、启用、更新、卸载后，引擎会在当前任务结束后自动重启生效
  • 装之前就判断手机能不能用：需要原生模块的插件，在下载前就拒绝并说明原因；装完再扫一遍，发现原生文件就回滚。依赖 dsh 网页版服务的插件（例如 DS-Bot）也会在安装时说明用不了的原因
  • 坏插件不会让 App 起不来：哪个插件导致引擎崩溃就自动暂停哪个；连续两次起不来时进入安全模式，暂停全部插件，再逐个恢复
  • 一次提示：安装卡片里如实说明插件拥有和智能体一样的能力，此外没有额外弹窗。插件工具在会话模式里归为“扩展工具”，“只聊天”模式默认关闭；每个插件可以单独打开“调用前问我”
  • 技能：从文件、zip、链接或 GitHub 导入 SKILL.md，不用重启
  • MCP：粘贴地址或 mcpServers 配置接入远程 MCP 服务；npm 上的纯 JS MCP 服务也能在手机上运行。需要 Python、Docker 的服务会明确说明不支持
  • 国内网络：插件下载源在 npmmirror 和 npm 官方之间自动选择，一个不通就换另一个
  • 可以从系统分享菜单“安装为 DSH 扩展”
  • 内置 dsh 升级到 0.2.1-rc.5；冷启动时间不变
  • 这版没有在真机上测试过，插件安装这条链路尤其需要真机验证
  • 仅支持 arm64-v8a，Android 10 及以上；正式签名，可直接覆盖安装 v0.1.1 及以后版本

v0.2.5
833166f
  • 修复第三方模型对话必失败（#20 #28）：很多 OpenAI 兼容网关（magpie、NVIDIA NIM、公司内网网关等）在流式返回里每帧都带 "usage": null，以前会被误报成“provider transport failed”并反复重试。现在正常对话；解析不了的返回会直接说“模型服务返回的数据格式不兼容”，不再伪装成网络错误、也不再空等重试
  • 接口地址没写 /v1 时，“获取模型列表”遇到 404 会自动试 /v1 并帮你改好地址；对话时的 404 也会提示试 /v1
  • 模型列表刷新（#25）：刷新后列表就是接口这次返回的模型；已勾选但接口不再返回的模型标“接口未返回”留在最上面
  • 上下文窗口和最大输出（#27）：不再写死 128K。能从接口返回里自动识别（vLLM、sglang、OpenRouter、llama.cpp 等），也可以按服务商或按模型手动设置；引擎和输入框的上下文圈都用这个值，并标明来源
