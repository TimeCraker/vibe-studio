## 1. 一句话定位

一句话的提示词「画一只骑自行车的鹈鹕」交给 Antigravity 里的 **Gemini 3.8 Flash**，
它交出来两版**可以点的 SVG 网页应用**：整屏场景、会动的角色、按铃逗鱼、三套昼夜主题。
Flash 是轻量档，不是旗舰档，所以看完之后的合理怀疑是：**这已经是 Gemini 4.0 的水平**。

**内容性质**：这是**观察 + 推断**，不是实锤。片尾说的是「水平更像」和「没有别的解释，只能往版本上想」，
建议发布时保持这个口径，别写成「确认已升级到 4.0」。

## 7. 视觉风格：作品集图版

不是常见的「深色霓虹科技感」，而是**印刷作品集**的排法：

- 暖白纸底 + 衬线大标题（Noto Serif SC），正文黑体（Noto Sans SC）
- 生成的动画以**图版**形式压在纸面，上下留纸；下沿一条**实心纸面字幕带**（不是半透明黑药丸）
- 书眉每帧常驻 `ANTIGRAVITY 生成实录 · PELICAN ON A BICYCLE` / `GEMINI 3.8 FLASH · 轻量档`
- 开场是一张**输入卡**：提示词 + 生成规格表 + 三张输出缩略图（联络表）
- 规格信息用**点线引导**表格；图注是**实心纸片 + 细引线**，没有发光、没有模糊投影
- 只有结论页翻成墨底，形成全片唯一一次明确的明暗转折

改风格只需要动 `edit/director.html`（设计变量与版式）和 `edit/director.js` 里的模板函数。

### 封面必须做「中心安全」构图

B 站**首页推荐按 4:3 裁、个人空间按 16:9 裁**，两者都是取画面中心。
所以封面是 1920×1080，但所有关键内容（眉题 / 标题 / 红条 / 结论胶囊）都被放在
中心 1440×1080（即 x 240 到 x 1680）之内。这样 4:3 那一刀既不会切掉标题，16:9 也只是左右多出背景。

> 踩过的坑：初版封面是「左边纸面标题 + 右边图版」的双栏构图，标题起在 x=72，
> 4:3 裁剪后左边被切掉，首页推荐里显示成「自行车的 / 鹈」。改版后重新上传才正常。
>
> 校验方法：`render/covers/cover-a-sunset.png` 用 PIL 从中心裁 1440×1080 看一眼即可。

## 8. 出处与可复跑

整条片子是**代码生成**的，不是剪辑软件手剪的，所以每一步都能复跑、能改：

| 步骤 | 命令 |
|---|---|
| 采集两版动画的 4K 逐帧画面 | `node tools/capture-all.mjs` |
| 校验剪辑方案（区间、锚点、字幕节奏、文案重复、页脚越界） | `node tools/validate-plan.mjs` + `node tools/probe-layout.mjs` |
| 渲染成片 | `node tools/render-director.mjs --out render/video.mp4 --crf 15` |
| 生成配乐 | `python tools/make_music.py` |
| 合成母版 + 导出字幕 | `node tools/assemble.mjs` |
| 抽帧审图 | `node tools/render-director.mjs --sample 150,2250 --out qa/x` |
| 生成封面 | `node tools/render-director.mjs --cover` |

改文案只需要动 `edit/timeline.js` 里的 `UNITS` 和 `CUES`；改配乐结构动 `edit/sections.json`
（音乐的重拍、riser、impact 会自动跟着新的段落边界走）。

### 诚实性说明

- 「Flash 轻量档」→ 你提供的模型标注（Antigravity 里的 Gemini 3.8 Flash），
  片头书眉常驻、输入卡规格表与结论页都据此表述。
- 「纯 SVG，没有一张位图」→ 全文检索两份 HTML：`<img>` / `data:image/png|jpeg|webp` /
  `background-image` / `<video>` / `<canvas>` **均为 0 处**，只有内联 `<svg>`。
- 「会眨眼、会呼吸、围巾一直飘」「按铃有反应」「点一下吐出鱼」「三档速度」「三套主题」
  → 逐帧抽图核对过，且与两份 HTML 的源码控件一致（`tools/probe-ui.mjs` 列出全部真实控件）。
- 图注位置 → `tools/probe-anchors.mjs` 读 `getBoundingClientRect` 拿到的真实元素坐标，
  不是估算的。
- **需你确认的说法**：「提示词就这一句」「两版都是一次生成 / 一次跑通」。
  这两句沿用你的表述，我没有独立证据；如果实际不是一次成型，改 `edit/timeline.js`
  里对应的 3 处文案即可（开场字幕、清单页 pull、结论页 side 行）。
- **未断言**：它**实际**是不是 4.0。片子只说「水平更像」和「合理怀疑」。
