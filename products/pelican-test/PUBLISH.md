在 Antigravity 里，用一个流传很久的老题目「画一只骑自行车的鹈鹕」实测 **Gemini 3.8 Flash**。
Flash 是轻量档，但两版 SVG 动画都一次成型，结构、运动学、细节全部自洽 ——
完成度高到让人怀疑：这已经是 **Gemini 4.0 的水平**。

建议发布时也保持这个口径，别写成「确认已升级到 4.0」。

## 7. 视觉风格

成片走的是**印刷图鉴风**，不是常见的「深色霓虹科技感」：

- 暖白纸底 + 衬线大标题（Noto Serif SC），正文用黑体（Noto Sans SC）
- 动画画面以「印刷图版」形式压在纸面上，下沿留一条**实心纸面字幕带**
  （不是半透明黑药丸，也不是渐变蒙版）
- 规格信息用**点线引导**的表格排版，不是圆角信息胶囊
- 图注是**实心纸片 + 细引线**，没有发光、没有模糊投影
- 只有结论页翻成墨底，形成一次明确的明暗转折（避免全片共用一个底）

改风格只需要动 `edit/director.html`（版式与设计变量）和 `edit/director.js` 里的模板函数。

## 8. 出处与可复跑

整条片子是**代码生成**的，不是剪辑软件手剪的，所以每一步都能复跑、能改：

| 步骤 | 命令 |
|---|---|
| 采集两版动画的 4K 逐帧画面 | `node tools/capture-all.mjs` |
| 校验剪辑方案（区间、锚点、字幕节奏、文案重复） | `node tools/validate-plan.mjs` |
| 渲染成片 | `node tools/render-director.mjs --out render/video.mp4 --crf 15` || 生成配乐 | `python tools/make_music.py` |
| 合成母版 + 导出字幕 | `node tools/assemble.mjs` |
| 抽帧审图 | `node tools/render-director.mjs --sample 300,2650 --out qa/x` |
| 生成封面 | `node tools/render-director.mjs --cover` |

改文案只需要动 `edit/timeline.js` 里的 `UNITS` 和 `CUES`；改配乐结构动 `edit/sections.json`
（音乐的重拍、riser、impact 会自动跟着新的段落边界走）。

### 诚实性说明

片子里出现的每条具体断言都经过核对，来源如下：

- 「Flash 轻量档」→ 由你提供的模型标注（Antigravity 里的 Gemini 3.8 Flash），
  片头书眉常驻、开场规格表与结论页都据此表述。
- 「车轮正圆 / 辐条等分 / 链条对齐 / 膝盖不反折 / 脚掌贴合踏板 / 无穿模」
  → 逐帧抽图人工核对过（本地 `qa/` 目录留有抽帧图，未入库）。
- 「纯 SVG 无贴图」→ 全文检索两份 HTML：`<img>` / `data:image/png|jpeg|webp` /
  `background-image` / `<video>` / `<canvas>` **均为 0 处**，只有内联 `<svg>`。
- 「轮速是踏频的 1.5 倍」→ 直接读源码常数（踏板角速度 4.2，车轮 ×1.5）。
- 标注点的位置 → 用 `tools/probe-anchors.mjs` 读取页面里对应 DOM/SVG 元素的真实屏幕坐标，
  不是估算的。
- **未断言**：两次用的提示词是否完全相同、以及它**实际**是不是 4.0。
  片子里只说「同一个题目独立跑了两遍」和「合理怀疑」。
