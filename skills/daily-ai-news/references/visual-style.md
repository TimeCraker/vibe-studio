# 已确认视觉与参考图

用户于 2026-10-23 认可新版封面/新闻页的主题风格，并要求停止继续生图，后续全部通过 vibe-studio 现有制作链完成。

## 在代码里保持的要素

- 浅纸白底（约 `#fbfaf7` / `#f3f2ed`）、墨色文字（约 `#1a1a18`）、少量珊瑚强调（约 `#a8513c`）。墨色用于文字和细节，不做大片黑底。
- 疏朗的科技杂志/报刊排版，大标题有层级和留白；细线克制，不做密集边框与控件式标签。
- 允许少量白色纸页图层、轻微旋转和柔和阴影，使用 CSS/SVG 实现。预览里的摄影级纸纹、自然光和景深可以简化；先保证阅读、布局与稳定渲染。
- 不使用黑底 logo 方块、黑底流程卡、输入→工具→结果的卡片示意，也不以发光、紫蓝渐变或机器人装饰填版面。
- 官方标志直接读取官方 SVG/PNG；模型名和新闻标题由数据提供，不让模型凭记忆重画标志。
- 字幕留安全区，短句清楚；榜单按实际画幅重排，完整保留前 15 条。动画由 Remotion 帧号驱动，不直接使用 CSS 自主播放动画。
