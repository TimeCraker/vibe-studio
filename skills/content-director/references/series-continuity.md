# 系列视频一致性

适用于连续栏目、同一产品的多条教程或品牌视频。一次性作品直接沿用本片视觉方向，无需建立栏目系统。已有成熟系列先查实际源文件和代表片段，继续使用有效方案。

## 固定什么，允许什么变化

在已有 brief.md 的系列段落写清栏目来源/版本、需要延续的要素和本期例外。优先固定识别与理解成本高的部分：字体层级、颜色语义、图解/标注语言、字幕结构、声音方向、片头片尾及封面家族。布局、镜头长度、明暗与信息密度随内容调整，不要求每期复刻同一构图或使用相同特效。

例如同一教程系列可以延续“关键操作用同一强调色、结果用相同标注、字幕保持同一层级”，本期流程镜头用 SVG，下一期实操镜头用录像。统一的是表达语言，真实产品界面仍按当前版本展示。

## 把约定落到已有工程

| 约定 | 在哪里实施 | 如何核对 |
|---|---|---|
| 字体/色彩/字号与图形语义 | B 线项目中的 scene-kit/tokens.ts、fonts.ts 及实际场景配置；C 线导演页样式 | 比较实际代表帧，检查字体加载、对比和标签语义 |
| 标题、字幕、圈注与封面 | 本项目字幕/圈注组件、时间轴和封面 props | 不同标题长度、横竖版与手机阅读尺寸下实际渲染 |
| 镜头与声音方向 | 分镜、实际音轨、audio.json（需要处理时） | 播放典型衔接、审听人声/配乐与片头片尾，避免只统一参数 |
| 复用代码与媒体 | 本项目中实际使用的组件、配方、素材与来源 | 能从本期保存的输入重建，不依赖共享文件未来不变 |

现有 B 线可从 video-motion 模板的 [tokens](../../video-motion/templates/remotion-app/src/scene-kit/tokens.ts)、[fonts](../../video-motion/templates/remotion-app/src/fonts.ts)、[DeckVideoV2](../../video-motion/templates/remotion-app/src/DeckVideoV2.tsx) 与 [CoverV3](../../video-motion/templates/remotion-app/src/CoverV3.tsx)入手，先查组件是否实际读取要改的参数；字幕、封面和部分场景可能独立设值，不能只改 tokens 就声称全片已统一。C 线核对 edit/director.js、页面样式和 edit/timeline.js 中的实际取值。A 线保留所用剪辑工程、预设和依赖说明，不虚构可执行代码模板。

只调整当前系列需要的少量真实配置，使用当前帧驱动接口；发现相同值散落时在本项目内做必要收敛。没有稳定重复需求时不引入新主题系统、全局配置格式或运行时动态加载。

## 系列与本期各保留一份正本

有已验证且需要复用的栏目方案时，按[资产回流约定](../../../assets/README.md#有复用价值时回流)在共用库保存一份系列说明和必要模板/参考帧，例如 assets 下的 series/<栏目 id>/；未形成可用方案前不建空目录。只保留有效默认值、来源/版本和真实参考，不复制每期完整策划。

新一期把实际使用的配置、代码和素材带入项目，在 brief 中引用系列版本（提交/版本或实际输入哈希）及本期差异；项目内代码与输入是该期复现依据。已有栏目说明只保存共享默认，不再同步更新一份本期副本。系列调整不会自动升级旧片或已归档 recipe，也不直接覆盖正在制作的其他项目。

简报可用几行表达，无需填满所有字段：

```markdown
## 系列
沿用：栏目方案的实际位置与版本
本期保留：强调色语义、字幕层级、封面家族
本期差异：实操镜头替换原理图；竖版重排结果区域
实施：链接本项目实际配置/代码与输入素材
检查：链接本期代表帧/短片及已查看或待审范围
```

## 验证一致性

选择能暴露差异的片头、实操/图解、字幕、转场和封面片段，与既有已接受样例对照。检查本期长标题、真实截图和不同画幅，不能只用上一期短文案演示模板。按影响核对视觉与声音，不设固定帧数或额外审稿轮次；没有系列样例或未听音时明确缺项。media-qc 记录实际视听观察，一致性不自动等于本期叙事有效或人工接受。
