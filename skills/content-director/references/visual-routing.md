# 视觉能力选路

先看镜头要解释什么，再选制作方式；同一片可混用。已有稿件、品牌、素材和审阅结论直接复用。把选择与代表画面写进已有 brief.md，不另维护技能清单或审批表。

| 需求 | 调用方式 | 本片应拿到什么 |
|---|---|---|
| 视觉方向、版式、封面排版 | 环境可用时按需读取 design-skill；导演保留本片决策 | 字体层级、色板、构图和代表画面，落到实际项目代码/素材 |
| 插画、背景、封面主图或透明位图 | 读取当前 imagegen 技能，结合[美术简报](art-brief.md)调用实际工具 | 已生成并保存到项目的图片、来源和使用记录 |
| 原理、架构、流程、数据、前后对比 | video-motion 的[技术可视化方法](../../video-motion/references/visual-production.md#技术可视化) | 有真实内容依据的 SVG/图形场景与可播放片段 |
| 已有 Lottie 动画素材 | 有选材或网页接入需求时读取 lottie；视频制作使用现有 LottieLayer | 本地素材及外部依赖、明确的播放区间和实际渲染 |
| 实体产品、结构或空间关系 | 复用 ThreeStage，按[3D 分支](../../video-motion/references/visual-production.md#3d-产品与空间镜头)施工 | 有来源的模型/贴图、相机/光线与帧驱动镜头；模型未就绪先交示意图 |
| 地图叙事、Studio 内可编辑元素 | 核对官方 maps/interactivity 指导及锁定引擎接口 | 实际可渲染或可编辑的本项目实现，具体步骤见[专项分支](../../video-motion/references/visual-production.md#remotion-官方专项) |

## 调用边界

- design-skill/imagegen/lottie 属于环境共享能力，不在本仓复制安装。使用前按当前技能目录发现并读取；不可用时沿用本地模板、SVG/已有素材并明确缺项，不声称已经调用。无需仅为归类新增同名项目 skill。
- 只读取命中任务的共享技能部分。设计技能提供构图与可读性建议，本片品牌、真实产品样貌及渲染约束优先；网页字体偏好、默认动效强度、屏幕滚动和 autoplay 规则不直接变成视频规范，也不因此另建网站或引入新前端栈。
- Remotion 画面由实际帧号驱动。Lottie 的网页自动播放、CSS 自主动画、Three.js 的实时循环不能直接移入视频渲染；具体时序和接口以本仓组件及锁定依赖为准。
- 真实操作、产品界面与数据证据使用真实材料；生成图、模型和示意图说明概念时保留身份，不作为产品真实效果证明。
- 选代表画面/关键片段先验证，再扩展到全片。新素材存入项目；进入共用库以来源清楚和复用价值为条件。最终仍走动态分镜/样片、声音后期与 media-qc，技术成功不能代替实际视听接受。
